## Dropi EC: regra atual

O sistema pode buscar/sincronizar pedidos da Dropi e avisar clientes conforme status, mas envio de pedido novo para Dropi nao e automatico.

Fluxo correto:

1. Voce escolhe o pedido.
2. Voce autoriza o pedido para envio:

```text
POST /api/shipments/droppi/ec/orders/:orderId/authorize-submit
```

3. O sistema registra:

- `automation.dropiSubmitAuthorizedAt`
- `automation.dropiSubmitAuthorizedBy`
- `automation.dropiSubmitAuthorizationNote`
- evento `dropi_submit_authorized`

4. O lote de envio so processa pedidos autorizados:

```text
POST /api/shipments/droppi/ec/dispatch/run
```

5. Antes de enviar de verdade, usar dry-run:

```json
{ "limit": 10, "dryRun": true }
```

6. Para enviar de verdade, usar somente depois da confirmacao:

```json
{ "limit": 10, "dryRun": false }
```

7. Para remover autorizacao:

```text
POST /api/shipments/droppi/ec/orders/:orderId/revoke-submit-authorization
```

Sem autorizacao manual, o dry-run e o envio real retornam fila vazia.
